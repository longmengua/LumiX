# LumiX 文件總覽

本目錄依主題保存產品、架構、工程與營運規格。AI 開發先讀根目錄 `AGENTS.md`、`AI_AGENT.md`，再依 `ai/AI_CONTEXT_ROUTING.md` 找到任務所需文件。

- `reference/` 專案總覽與詞彙。
- `architecture/` 系統架構與資料流程。
- `exchange-core/` 交易、帳本、錢包與風控規格。
- `engineering/` 共用程式碼規範。
- `governance/` 安全、資產、UI 與正式上線門檻。
- `operations/` 部署與維運。
- `product/` 產品與業務範圍。
- `ai/` AI 開發入口與 UI 實作快照。
- `adr/` 架構決策紀錄。
- `templates/` 共用文件模板。

新增文件請放入對應主題目錄。後端與前端的實作文件分別放在 `server/docs/` 與 `web/docs/`。架構圖、流程圖與資料圖使用純文字。
