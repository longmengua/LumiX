# LumiX Delivery

## 目前有效指示

使用者於 2026-11-21 取消 AI 施工流程限制。免逐卡批准、免新增測試確認、不受 phase 順序限制；本 skill 不得恢復這些限制。

## 工作與交付

- 先確認工作目錄，讀取與任務直接相關的程式碼、設定及文件；歷史 phase 文件不存在時，以目前實作與使用者要求為準繼續工作。
- 依實際技術相依完成授權功能，可跨 phase 實作；phase 與 task card 僅作背景參考，不限制施工順序。
- 直接新增必要測試並執行適合此次變更的驗證，保留實際結果、未驗證項目與限制。
- 高風險變更保留 `HUMAN_REVIEW_REQUIRED` 提示與稽核證據；提示不要求開發或測試前批准。
- 更新必要的實作及進度文件。以可獨立驗證的完整變更為交付單位，不必等待整個 phase 結束。
- 使用者已授權提交／推送時即可交付。提交前檢查 git status，不把無關變更混入；回報 commit、push、測試及未完成事項。
- 技術相依、資金安全、資料完整性、對外動作權限與正式上線判定不因取消流程限制而改變；不得以 fake／mock runtime 或未驗證成功狀態冒充完成。
