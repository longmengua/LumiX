# LumiX Delivery

## 先判斷本次任務的流程授權

以 repository `AGENTS.md` 的「任務限定的 AI 施工流程豁免」為準。若使用者開工時明確表示可以跳過 AI 施工限制、不需要人工批准或同義指示，立即套用豁免，不再要求逐卡批准、implementation review 或新增測試確認，也不以 phase 順序或整個 phase 才能交付作為停工條件。

豁免僅延續於同一任務；新任務未指定時依原有流程。技術相依、資金安全、資料完整性及正式上線判定仍須由實作與驗證證明，不能以豁免代替。

## 工作與交付

- 確認工作目錄，讀取任務直接相關的程式碼、設定及文件，避免讀取整份歷史文件集。
- 一般流程依 phase／task 相依施工，更新階段證據，完成 phase 後獨立 commit／push；遵守當時有效的 approve 與測試規則。
- 豁免流程依實際技術相依完成授權功能，可跨 phase 實作，直接新增必要測試；以可獨立驗證的完整變更為交付單位，不必等待整個 phase 結束。
- 執行適合變更的驗證，記錄實際結果、未驗證項目及限制。保留必要的繁體中文註解、稽核證據與 `HUMAN_REVIEW_REQUIRED`；豁免期間此提示不構成人工批准前置條件。
- 同步必要的實作及進度文件。使用者已授權提交／推送時即可交付；提交前檢查 git status，不混入無關變更。
- 回報完成能力、commit／push、測試及未完成事項，不以 fake／mock runtime 或未驗證成功狀態冒充完成。
